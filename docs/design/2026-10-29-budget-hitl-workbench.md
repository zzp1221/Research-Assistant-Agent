# 预算链路与人在回路工作台改版

- 状态：已实现并验证
- 日期：2026-10-29
- 范围：`research-assistant/frontend`
- 关联：`docs/design/n01-n03-plan-library-reproducibility-cost.md`、`docs/design/n05-plan-review-hitl.md`

## 一句话

把新增的预算链路与人在回路能力从「一排按钮 + 多个重叠横幅」变成「一条状态带 + 一个工作台菜单 + 一个待办中心」；保留全部功能，但把入口按任务而不是按组件归位。

## 用户任务

- 研究者需要随时知道：计划处于什么状态、预算用了多少、有哪些事在等自己决定；
- 需要在一个地方处理运行时审批、计划提问和计划审阅，而不是在多个面板之间找；
- 不需要在首屏看到所有工具按钮和所有状态文字。

## 三个方向

对比页：`style-explorer.html`（候选目录 `explore/`）

| 方向 | 核心 | 首屏骨架 |
| --- | --- | --- |
| A · 指挥条 · 一栏状态带 | 计划 / 预算 / 待办 / 审阅 / 权限收进一条可点击状态带；工具收进一个「工作台」菜单 | 顶部身份条 + 状态带 + 对话/执行图分栏 |
| B · 侧轨 · 任务指挥台 | 工作区导航移到左侧竖轨，右栏常驻任务板（预算环、待办直批） | 竖轨 + 中间画布 + 右侧任务板 |
| C · 任务板 · 研究卷宗 | 横向执行卷宗，预算写在步骤上，右栏只留待办与预算账本 | 大标题 + 横向六步 + 右侧任务板 |

选择 **A**：它保留现有纸张与编辑部识别度，改动集中在信息层级而不是重写布局；预算与待办成为首屏可读状态，同时不挤占执行图画布。对比图：

## 关键改动

### 首屏减负

- 顶部 6 个工具按钮（计划库 / 成本 / 审阅 / 收件箱 / 使用手册 / 模型设置）收进一个「工作台」菜单，只保留身份、计划状态和主操作。
- 新增 40px 状态带，五段可点击：计划、预算、待办、审阅、权限。预算显示已用/预留/限额，待办显示审批与提问数量，审阅显示是否等待批准。
- 执行图头部去掉 5 列统计条和重复的意图/模板徽标；节点统计进入一行紧凑元数据。
- 待回答问题、运行时审批、缺失材料合并为执行图头部一个「待办 N」按钮，默认收起，展开后仍可逐项处理。
- 计划库卡片动作收进「更多」菜单；意图与归档筛选收进「筛选」弹层。
- 「新建项目」从无提交语义的图标按钮改为可见表单：输入名称后按 Enter 或点「创建」，创建后自动选中新项目。
- 使用手册新增「预算与待办」章节，移除冗余眉标并提高正文可读性。

### 预算链路

- 新状态带直接显示预算：已用、预留、限额、80% 预警、100% 策略。
- 成本面板改为「预算状态 hero + 趋势 / Top 列表 + 右侧预算设置与预警」两栏结构；明确展示「派发前预留 → 执行中计量 → 完成后结算 → 80% 预警 → 100% 按策略暂停/取消」。
- 成本面板保留精确到 4 位小数的金额口径，便于核对 usage。

### 人在回路

- 待办中心聚合运行时审批和计划提问；审批卡增加「批准一次 / 拒绝 / 打开计划」，高风险仍逐条确认。
- 计划审阅的预算字段从底部移到 revision 摘要下方，先看到预算再编辑节点。
- 审阅、待办和预算都从状态带进入；没有活动计划时审阅入口置灰，不再出现无意义按钮。

## 动效

- 工作台菜单与待办展开沿用 `proof-fade`；
- 状态切换不新增循环动画；运行中 `proof-pulse` 保留。
