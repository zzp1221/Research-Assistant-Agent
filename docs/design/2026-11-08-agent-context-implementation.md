# Agent 上下文集成与恢复修复

日期：2026-11-08；分支：`feature/agent`。

范围说明：本文记录本轮首先完成的 AG-04 专项，下面的测试数量和环境状态属于该阶段。后续 AG-01–AG-06 的集成、配置、前端反馈与最终验收以 [六线实施与验收](2026-11-08-agent-capability-implementation.md) 为准。

依据 [Agent 能力改进方案](2026-11-07-agent-capability-improvement.md) 的 AG-04，补齐已有 [上下文实现](2026-11-07-context-implementation.md) 的 Agent 集成缺口。对照 `feature/context` 当前代码，“固定 1024 输出”“修复会话只存 hash”等现状描述已不再成立，本次沿用现有模型预算、ContextStore 和完整消息快照。

## 已实现

- 自定义 Profile 接收计划、上游输入、Memory/Wiki 和冻结任务契约，使用共享分区组装；模板使用的值去重，变量被覆盖时保留原始输入作为证据。参考材料不提升为系统指令。模型在组装前固定一次，预算与生成使用相同 revision；支持持久化 JSON 恢复后的模板变量。
- ResearchCodingAgent 继承 Coder 的模型运行时。AutoResearch 候选、Benchmark adapter 修复和 Paper Debug 修复会话，以及 Claim Evidence、Ablation、依赖/Python 修复等辅助文本调用，接入实际模型预算与上下文持久化。独立阶段使用各自分支，修复会话的连续轮次沿用同一分支。固定模型注入的测试/独立调用保持兼容。
- 调度上下文键包含 owner/project/session/plan/task/revision；同一任务重试可复用已提交窗口，新 revision 与并行任务隔离。任务执行身份继续传递；当前研究约束、冻结契约和网络审批状态随调用重新发送。托管上下文不受旧 Prompt 拼接开关影响。
- 修正附件去重从附件标题截断整个后文的问题，父计划摘要、父计划 ID 和记忆仍保留；托管模式的论文元数据不再预先按 4000 字符截断。
- 文本摘要提交时同步保存全部依赖材料的 hash 前缀。压缩成功后生成失败，重启可复用摘要；修改或缩短历史会重建，避免旧摘要污染和切片越界。
- 请求去重纳入实际模型版本、解析后的预算和请求选项。修改窗口或输出上限后重新预检，不因旧回答缓存绕过容量限制。
- 调度器保存上下文引用、预算、模型版本、Memory/Wiki 引用和修复快照；失败路径也经现有 execution fence 提交，旧 worker 不能覆盖新诊断。传入的模板变量/修复快照复制后交给运行器，避免提前修改持久任务对象。

新增回归覆盖 Profile 上游/计划/记忆材料、模板变量覆盖、实际模型固定、长材料完整传递、论文/附件去重、三种科研修复会话的模型路由和预算、快照还原与新 Resolver 续接、独立调用分支与缓存、超限请求零 HTTP、摘要后生成失败再重启/编辑/缩短历史、窗口缩小、revision/并行任务隔离、失败快照保存和迟到 worker 拒写。

## 交付边界与迁移

继续使用已有模型配置、能力声明和 ContextStore，无新增服务商能力假设。已启用压缩的模型按原配置工作；未启用的模型保持容量预检。托管 Agent 路径现在会明确报出模型窗口不足，不能依赖旧的静默裁剪来绕过输入限制。

调度分支键和请求去重键变更后，旧任务首次调用会从现有业务材料重建新窗口，旧 generations 保留。无独立 schema 迁移；原始证据和长期记忆不会被压缩摘要替代。

修复快照与活动窗口可恢复，不等于整个科研执行器已有可自动恢复的副作用账本。后续 AG-01/02 已加入 Profile 工具检查点、确认结果续接、未知副作用阻塞、动作账本与共享恢复额度，详见总报告及 [分类恢复说明](2026-11-08-recovery-memory.md)；仍不会仅凭快照自动重放任意已执行 patch 或实验，也未交付运行中全自动安全重规划。本专项报告不单独宣称六线全部验收完成。专用材料选取器的资源/节选限制及独立图像调用仍有各自边界，不宣称全部原始材料均进入模型。

现有 Compose 容器曾因 Docker 重启退出；已恢复原服务，并在确认数据卷无运行 writer 后清理两处遗留 PID=1 锁。运行服务的镜像未重建为本次源码；本次代码通过挂载源码的测试容器验证。收尾清理临时测试容器，运行数据、正式服务与依赖缓存保留。旧 `tmp/` 仅含历史审查日志、探针、二进制等未跟踪产物；其删除被执行工具安全策略以 `blocked by policy` 拦截，保留原目录并加入忽略规则，未把忽略等同于删除。
