# Research Assistant · UI 升级设计说明（feature/ui）

> 对象：Research Assistant Agent 科研工作台（React + Vite + Tailwind 4）
> 分支：`feature/ui`　　日期：2026-10-26
> 本文先立设计判断与交互规则，再据此做界面。界面实现与本文不一致时，以本文为准并回改实现。

---

## 1. 现状诊断（实测，非印象）

在 1440×900 首屏实测当前工作台：

| 观察项 | 现状 | 问题 |
|---|---|---|
| 左栏宽度 | 475px（33%），内部再分 header / 会话 / 消息 / 推荐指令 / 权限说明 / 输入框 六层 | 层级多、视觉噪音大，输入区被挤出主要视线 |
| 字号分布 | 10px ×16、10.5px ×16、11px ×13、11.5px ×9；正文 13.5px | 靠 10–11.5px 小字撑"精致"，实际阅读困难 |
| 装饰语法 | 圆角 5–10px 卡片 + 胶囊标签 + 大写字母眉标 + 每层描边 | 典型的"AI 生成 UI"语法：到处是徽章和卡片 |
| 主题 | 米色纸感底 #f5f2ea + 墨绿 #2c5a4d + 衬线标题 | "论文纸"隐喻停留在配色，信息结构仍是聊天机器人 |
| 文案 | "🎉 Agent 思考与执行完毕"、"哎呀，与后端失联了 📡"、✅❌ 表情 | 与科研工具的严肃语境冲突 |
| 状态表达 | 意图、outcome、模板规划、权限、ToT、Search Agent 六个徽标并排 | 重要状态被平铺，用户分不清轻重 |

结论：问题不在"颜色不够学术"，而在**信息架构仍是一个聊天应用**——对话、计划、执行三件事被塞进并排的两个卡片栏，状态靠徽标堆叠，操作靠重复按钮。升级要同时改骨架、语法和状态逻辑。

## 2. 北极星与调性

**北极星：像一台校准过的科研仪器——状态永远可读，动作永远有回执，装饰为零。**

五个刻度（依据：研究者长时间盯屏、任务以小时计、结果需要审计）：

| 刻度 | 取值 | 依据 |
|---|---|---|
| 能量 | 安静 | 低饱和、无渐变、无光晕；注意力留给数据和异常 |
| 完成度 | 精致 | 1px 公差、4px 网格、无阴影堆叠；仪器感来自对齐而非装饰 |
| 密度 | 密 | 科研工具默认高密度，但用留白和细线分组，不靠小字压缩 |
| 分量 | 中偏重 | 顶部深色仪器条与表头压住画面，主体轻 |
| 严肃度 | 庄重 | 直角 2px、无弹跳、无表情符号、文案陈述事实 |

模糊词翻译：
- "减少 AI 前端味" = 去掉胶囊徽章、渐变、圆角卡片套卡片、大写眉标、表情符号、无意义的"✨ Sparkles"装饰；一屏最多两个强调色，其余交给排版。
- "符合科研" = 表格化、可对齐的数字、版本/时间/哈希等标识用等宽字体、状态用灯位与字形而不是色块、报告区用衬线阅读字体。
- "优化交互与显示逻辑" = 一屏一个主动作；选择联动（图 ↔ 台账 ↔ 检查器）；权限模式常驻可见但解释收进浮层；运行时间与进度可见；错误带可执行下一步。

## 3. 三个方向（见 explore/a.html、b.html、c.html）

三个方向共用同一份示例内容（Apriori 复现，8 节点，4 完成 / 1 待审批 / 3 等待），骨架、字体、色彩、主视觉四项互不相同。

### 方向 A · 仪器台（Instrument Bench）
- **北极星**：一台校准过的实验仪器，运行轨迹本身就是界面。
- **生成引擎**：实验室仪器面板 + 图表记录仪。来源是产品真正在做的事——按节点推进的可审计执行。
- **骨架**：深色仪器顶栏（40px）+ 左栏会话/指令 + 右侧执行台（台头 / 元数据条 / 权限动作条 / 铺满的画布 / 运行标尺 / 节点索引条）。计划图是主角，不是卡片。
- **字体**：Segoe UI Variable Display/Text + Noto Sans SC；数值与编号一律 Cascadia Mono、tabular。
- **色彩**：冷灰 #EDF0F2 / 白面 #FFFFFF / 墨 #0F1418 / 普鲁士蓝 #1B4D6B（主操作）/ 琥珀 #94600B（待处理）/ 深绿 #2C6A4A（通过）/ 砖红 #9E2F26（失败）。
- **主视觉**：画布上的毫米方格 + 底部"运行标尺 + 节点索引条"（记录仪纸带）。
- **记忆点**：节点完成时索引条上的段落填色、标尺上"现在"的游标随执行推进。
- **结构性突破**：计划图下方常驻一条与图形同构的**运行索引条**，图形与时间轴一一对应，取代传统侧边节点列表。

### 方向 B · 论文校样（Journal Proof）
- **北极星**：一份正在被审阅的论文校样，执行记录是页边批注。
- **生成引擎**：学术期刊排版（masthead、图注、表注、页边校样符号）。
- **骨架**：刊头 + 对开双页（左页正文与批注，右页图 1 与表 1）+ 底部批注栏。
- **字体**：Noto Serif SC / Source Han Serif SC + Georgia；控件用无衬线小字号。
- **色彩**：纸白 #FBFAF7、墨 #17130F、校样红 #8C2C2C、细线 #D8D0C2。
- **主视觉**：带图注和比例刻度的"图 1 执行拓扑"。
- **记忆点**：页边逐条盖下的校样符号（✓ / ✗ / ○）与红色批注线。

### 方向 C · 观测站（Night Observatory）
- **北极星**：夜间观测台的控制台，一切读数都在暗适应下可读。
- **生成引擎**：天文台夜间红光/琥珀照明 + 示波器。
- **骨架**：全屏画布为底，会话、检查器、运行谱三块 HUD 浮在上面。
- **字体**：Segoe UI Variable + Cascadia Mono，大号等宽读数。
- **色彩**：夜空 #080C10、面板 #111820、文字 #D9E3EA、琥珀 #F2A03C、青 #6FD0DC。
- **主视觉**：带坐标刻度的星图式 DAG。
- **记忆点**：底部运行谱的实时波形与节点脉冲。

**用户选定：02 论文校样 · Journal Proof**（2026-10-26 复审后确认）。第一轮曾推荐 A（仪器台），用户从对比页选择 B 后按 B 重做整套界面。B 的核心判断：把工作台做成一份**正在被审阅的论文校样**——刊头、对开双页、图注、表注与页边批注共同承担信息层级；执行状态用校样符号（✓ ◐ ○ ⚠ ✗）表达，而不是彩色徽标。

## 4. 视觉系统（方向 02 · 论文校样）

### 4.1 色彩

| 令牌 | 值 | 用途 |
|---|---|---|
| `--paper` | #f4f1ea | 书桌底色，页面之外 |
| `--surface` | #fbfaf7 | 纸张本体 |
| `--surface-muted` | #f4f1ea | 表头、批注底 |
| `--surface-strong` | #e8e3d9 | 行内代码底、选中底 |
| `--ink` | #17130f | 正文与主按钮 |
| `--ink-soft` | #3b342c | 次级正文 |
| `--muted` | #6b6156 | 辅助说明 |
| `--line` / `--line-strong` | #d8d0c2 / #bdb2a0 | 分隔 / 框线 |
| `--proof` | #8c2c2c | 校样红：待批、失败、当前项 |
| `--ok` / `--warn` | #14603f / #7a4a12 | 已校 / 在排 |

规则：全页只有墨与纸两种色相，加一支校样红；不用渐变、光晕、彩色阴影。

### 4.2 字体与字号

- 正文与标题：`"Noto Serif SC", "Source Han Serif SC", "Songti SC", Georgia`
- 标签与控件：`"Segoe UI Variable Text", "Segoe UI", "Noto Sans SC"`，字距 0.12–0.16em，全大写仅用于短标签
- 数字与编号：`"Cascadia Mono"`，`tabular-nums`
- 字号：报头 22px；正文 13–15px（行高 1.72–1.85）；辅助 11–12.5px；**任何文字不小于 11px，成句说明不小于 12px**

### 4.3 空间与形状

- 零圆角。所有框线 1px，报头下 2px 双线（`box-shadow` 模拟第二道）。
- 图版内边距 16px，网格 16px；正文列最大 68ch；表格行高 26–28px。
- 不为每个层级加框：用留白与细线分组，只有图版和授权单使用完整矩形框。

### 4.4 控件语法

- 按钮：直角、高 28px；主按钮墨底纸字，次按钮 1px 描边；按下 1px 下沉；禁用为纸灰底 + 深字（保证对比度）。
- 输入：1px 墨框，聚焦加 1px 外描边；不用圆角与阴影。
- 选中：表格行底色 #f4f1ea + 序号转校样红；图版节点 2px 墨描边。
- 状态：校样符号优先（✓ ◐ ○ ⚠ ✗），颜色是第二信号；标签用「已校 / 在排 / 待校 / 待批 / 退改」。
- 图标：仅在可加快识别处使用，16px、1.5 描边；纯图标按钮必须有 aria-label。

### 4.5 动效

1. **主操作反馈**：按下 1px 下沉；计划进入执行时，「运行校样」通栏出现 2px 校样红脉冲线。
2. **状态切换的来路**：批注栏 220ms 从右侧滑入（仅位移，不淡入——半透明首帧会掉对比度）；表格行选中即时换底色。
3. **首次进入**：刊头 → 通栏 → 双页按阅读顺序各出现一次（3px 位移，180ms，间隔 40ms），只播一次。
4. **记忆点**：图注随节点数实时改写；节点完成后表 1 对应行的状态由「待校」变「已校」，序号转校样红。

手感：纸与压印——短促、无弹跳，150–220ms，cubic-bezier(.2,.8,.2,1)；`prefers-reduced-motion` 全部直达终态。

## 5. 交互逻辑与显示逻辑

### 5.1 一屏一个主动作

图版页头右侧只出现一个主动作，按状态切换：运行计划 / 审批并运行 / 取消计划 / 重试失败节点。批注栏内的节点级操作是描边次按钮，不与整图执行抢主次。

### 5.2 三处联动

- 图版节点 ⇄ 表 1 行 ⇄ 批注栏：点任一处的节点，另外两处同步；表 1 支持 ←/→/Home/End，双击行打开批注栏，Esc 关闭。
- 图版底部常驻图注，说明节点数与依赖数；悬停节点只加深描边，不弹卡片。
- 批注栏宽 380–440px，打开时图版自动收缩，关闭后恢复。

### 5.3 权限模式

- 常驻在「投稿说明」底部与运行校样通栏：两段式开关（确认模式 / 完全权限）。
- 说明收进 `?` 的 title 提示，不再常驻一段灰字。
- 切到完全权限仍走授权单：表格式风险清单 + 勾选「签署并启用」。

### 5.4 运行操作审批

- 有待批动作时，图版上方出现「校样批注 · 需要作者决定」条，列出操作、类型、风险、影响与预计耗时；右侧「拒绝 / 允许一次」。
- 拒绝后计划转 blocked，批注条替换为缺失材料清单。
- 多条待批折叠显示数量。

### 5.5 消息流

- 不再使用气泡：每段按「§序号 / 角色 / 衬线正文」排布，角色写作作者、校样、助手。
- 系统事件（计划生成、节点完成、失败）作为低对比段落，不抢注意力；取消所有表情符号。
- 推荐指令改为「起始选题」编号列表，只在空会话出现。

### 5.6 显示逻辑

- 报头承载计划号、节点数、完成数、待批数与运行状态；版本记录（意图类型、规划来源、结果状态）收进 `⋯`。
- 缺失项以「名称 + 原因 + 建议」列出。
- 批注栏顶部固定四行规格表，下方才是日志 / 代码 / 报告 / 图表 / 证据 / 实验六个视图；日志为深墨底浅字，报告为衬线正文最大 68ch。

### 5.7 空态 / 错误态 / 加载态

- 空态：空图版 + 「图 1 · 执行拓扑（待排版）」+ 三条起始选题，不画虚线卡片。
- 加载：骨架用真实的图版/表框轮廓。
- 错误：一句话说明 + 一个可执行动作，不出现语气词。

## 6. 实施记录（方向 02 · 论文校样）

- **刊头**：报头三段式（左：Research Assistant / Manuscript Workbench；中：The Research Proof + 卷期；右：计划号与账号），下方一条「运行校样」通栏，承载节点数、完成数、待批数与运行状态。
- **对开双页**：左页是「当前稿次 → 正文·校样批注 → 投稿说明」；右页是「图 1 执行拓扑 + 图注 + 表 1 执行记录摘要」。图版有 1px 黑框和 16px 网格，节点为纸白底、顶部 2px 状态色、编号以「图 01」形式标注。
- **页边批注**：检查器改为批注栏，顶部是「页边批注 / 负责者」，下方四行规格表（负责者、状态、任务类型、节点编号），主操作降级为描边按钮。
- **校样符号**：✓ 已校 / ◐ 在排 / ○ 待校 / ⚠ 待批 / ✗ 退改，符号为主、颜色为辅（墨绿 / 琥珀 / 砖红）。
- **表 1**：执行记录摘要以表格呈现，四列（序号 / 节点 / 负责者 / 状态），可点击、可键盘 ↑↓←→ 导航，双击打开批注。
- **授权单**：完全权限确认改为表格式风险清单（镜像 / 依赖 / 数据 / 算力）+ 勾选签署，按钮文案「签署并启用」。
- **动效（三处基本）**：① 主按钮按下 1px 下沉，计划进入执行时「运行校样」右侧出现 2px 砖红脉冲线；② 检查器 220ms 从右侧滑入（只位移不淡入，避免首帧低对比）；③ 表格行选中时左侧序号转砖红、图版对应节点描边加深。记忆点：图注随节点数实时改写（「图 1　执行拓扑：8 个节点，7 条依赖」）。
- **排版纪律**：正文用 Noto Serif SC（13–15px / 1.72–1.85 行高），标签与编号用无衬线大写字母距 + 等宽数字；全站零圆角、零卡片阴影；分隔线一律 1px 且不重复。




## 7. 验收

- 首屏无小于 12px 的成句文字；正文对比度 ≥ 4.5:1；无横向溢出。
- 1440×900 与 390×844 两个视口完整可用；移动端保留"对话 / 流程"两个面板切换。
- 组件测试、单元测试、lint、build 通过；Playwright 视觉基线随本次改版更新。
