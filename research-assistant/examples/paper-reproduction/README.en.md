# Attention paper reproduction example

[简体中文](README.md) | English

A lightweight reproduction of `Attention Is All You Need` packaged as a reusable acceptance path. It pins `harvardnlp/annotated-transformer`, runs an attention-structure ablation in smoke mode, and validates the full chain from plan generation to sandbox artifact return.

## What it validates

```text
POST /api/plan
  -> Planner / PlanStore
  -> POST /api/plans/:id/execute
  -> Scheduler
  -> Librarian / Coder / Sandbox / Data Agents
  -> Docker Sandbox
  -> Artifacts and event history
```

A successful run must satisfy:

- Plan intent is `Paper_Reproduction` and every DAG node reaches `completed`.
- The selected repository is `https://github.com/harvardnlp/annotated-transformer`.
- At least `repo_url`, `run_metrics`, and `comparison_report` artifacts exist.
- Event history contains `plan_started`, `artifact_created`, and `plan_completed`.

## Run

Start the full stack, then:

```bash
cd research-assistant
python3 examples/paper-reproduction/run.py \
  --output /tmp/attention-paper-reproduction.json
```

The script uses only the Python standard library. It checks service health, creates and executes a plan, polls the terminal state, validates key artifacts and events, and prints a run summary without API keys. Pass auth through `RESEARCH_ASSISTANT_API_TOKEN` or `API_AUTH_TOKEN`; identity can be overridden with `RESEARCH_ASSISTANT_USER_ID` / `RESEARCH_ASSISTANT_SESSION_ID`. For a remote deployment:

```bash
python3 examples/paper-reproduction/run.py \
  --base-url http://YOUR_SERVER:8080 \
  --output /tmp/attention-paper-reproduction.json
```

Via Makefile:

```bash
make example-paper-reproduction
```

## Integration test

```bash
cd backend
REAL_PAPER_REPRO_TEST=1 \
SANDBOX_URL=http://localhost:8082 \
go test ./tests -run TestRealPaperReproductionFlow -v -count=1
```

This test requires LLM configuration, network access to the repository, and a running Docker Sandbox; `go test ./...` skips it by default.

Offline test (no LLM, network, or Docker):

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover \
  -s examples/paper-reproduction -p 'test_*.py'
```

## Acceptance metrics

A successful run should show:

| Item | Expectation |
|---|---|
| Plan state | All nodes `completed`, 0 failed |
| Repository | `harvardnlp/annotated-transformer` |
| Runtime | PyTorch CPU, fixed seed |
| Artifacts | At least `repo_url`, `run_metrics`, `comparison_report` |
| Events | `plan_started`, `artifact_created`, `plan_completed` |

## Scope

This is a structural forward smoke test. The system clones and scans the repository, but the ablation entry point is generated by the system; it does not download WMT14, train a full Transformer, or compute BLEU. CPU latency applies only to this small-tensor microbenchmark.
