This directory validates the full Claim-to-Evidence Graph chain: the test drives the real `RoutedTaskExecutor` through the Librarian and Data Agent task entries and checks:

1. `claim_rubric_extract` freezes the rubric before result adjudication.
2. The backend assigns stable Claim / Criterion IDs and computes SHA-256.
3. Scheduler artifact routing passes `claim_rubric` downstream as JSON.
4. `claim_evidence_build` references only real run artifacts.
5. The graph JSON is returned as independent `structured_data`.
6. Final criteria connect `run_metrics` and `comparison_report` with 100% evidence coverage.
7. The frontend evidence-graph component passes lint and production build.

The LLM interface is a local `httptest` server with fixed semantic responses; no API key is needed.

## Run

```bash
cd research-assistant
bash test/claim-evidence/run.sh
```

`run.sh` runs the Go golden test, then frontend lint and production build.

Go golden test only:

```bash
cd backend
go test -v ./tests -run '^TestClaimEvidenceExample$'
```

Update the golden graph:

```bash
cd backend
UPDATE_CLAIM_EVIDENCE_GOLDEN=1 go test ./tests -run '^TestClaimEvidenceExample$'
```

Preview rendering is optional and not part of acceptance; executable correctness is determined by the Go golden test and frontend production build.
