# Research Assistant · 工作台空间与信息层级

## 用户任务

当前界面把会话区与 DAG 区放在同一个横向页面里，整体偏小；同时功能按钮和说明文字过多。希望在保留对话、执行图、审批、预算、文献库、计划库等能力的前提下，让界面更干净明亮、降低文字密度。

## 三个方向

| 方向 | 首屏骨架 | 主要特征 | 适合 |
| --- | --- | --- | --- |
| A · 光阑 · 轻量空间工作台 | 64px 图标竖轨 + 344px 对话栏 + 满幅执行图画布 | 白绿、圆角、柔和网格；详情用浮层，顶部只留状态与预算 | 希望保留对话常驻、同时让 DAG 成为主角 |
| B · 信号台 · 深色任务控制台 | 顶部命令栏 + 左侧会话轨 + 中央画布 + 右侧节点详情 + 底部对话 dock | 深色石墨、橙色运行信号；审批/日志/产物贴着当前节点 | 长时间监控、需要同时看状态与日志 |
| C · 蓝图 · 上下分幕研究工作台 | 上半幅全宽执行图 + 下半幅全宽研究笔记与输入 | 冷白与钴蓝、蓝图网格、正交连线；上下分幕让两者都不再横向挤压 | 希望会话与 DAG 都获得整幅宽度、文字最少 |

## 推荐

推荐 **C · 蓝图 · 上下分幕研究工作台**。它最直接回应“会话区和 DAG 区共用一个横向页面显得偏小”：把两者改成上下两幕，各自拿到 1400px 左右的整幅宽度；顶部只保留状态、预算和待办图标，文字密度最低。A 适合需要长时间常驻对话的场景；B 适合监控与日志密集的场景。

## 方向卡

### A · 光阑 · 轻量空间工作台

- 北极星：像一间明亮安静的研究室，执行图是桌面上唯一的主角，对话是随手可用的侧栏。
- 生成引擎：材质 × 环境——磨砂玻璃、淡绿网格、柔和自然光。
- 首屏骨架：左侧图标轨；对话栏；执行图画布；底部一条极简状态栏。
- 字体：Aptos / Segoe UI Variable + Cascadia Mono；标题 27px，正文 13.5px。
- 色彩：纸白 #F7F9F4、森林绿 #1F6B4F、嫩绿 #D8F26A；来自实验室器皿与植物标本。
- 主视觉：带光晕的执行图节点，活动节点有进度环。
- 控件语法：14–18px 圆角、1px 描边、低对比阴影；主操作只保留一个实心绿按钮。
- 放弃：横向工具条、重复的统计行、满屏小标签。

### B · 信号台 · 深色任务控制台

- 北极星：像任务控制台一样，当前运行状态一眼可读，所有操作都贴着当前节点。
- 生成引擎：其他领域的表现形式——航天/信号控制台的暗色仪表与橙色信号。
- 首屏骨架：顶部命令栏；左侧会话轨；中央执行图；右侧节点详情；底部对话 dock。
- 字体：Bahnschrift + Cascadia Mono；标题 22px，正文 11.5–13.5px。
- 色彩：深空黑 #070C10、石墨 #0E1A21、信号橙 #FF6B3D、薄荷 #72DFB1。
- 主视觉：带雷达环的橙色活动节点和流动虚线。
- 控件语法：6–11px 小圆角、细描边、发光只给运行中状态。
- 放弃：大面积白色、装饰性插画、重复说明文字。

### C · 蓝图 · 上下分幕研究工作台

- 北极星：把研究过程当成一张工程蓝图：上面看结构，下面写判断；两块都拥有整幅宽度。
- 生成引擎：一场设计运动——工程制图/蓝图语法，来自研究计划本身的结构性。
- 首屏骨架：顶部细命令栏；上半幅全宽执行图；下半幅全宽研究笔记 + 输入区。
- 字体：Georgia / Noto Serif SC 标题 + Segoe UI 正文 + Cascadia Mono 数字；标题 17px，正文 12–13.5px。
- 色彩：冷白 #F3F6FD、纯白 #FFFFFF、海军蓝 #0B1B3A、钴蓝 #1F4DFF。
- 主视觉：蓝图网格上的钴蓝活动节点与正交连线。
- 控件语法：5–9px 小圆角、1px 蓝灰描边；主操作钴蓝，警告只用琥珀。
- 放弃：左侧导航栏、常驻详情栏、卡片网格。
